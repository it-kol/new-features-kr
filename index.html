선택 영역 번역 · 만능 화면 번역

자막 번역은 "소리"만 번역할 수 있지만, 화면 속 글자는 "픽셀"입니다 — 영상 속 텍스트, PPT, 만화 말풍선, 화면 공유报表, 원하는 영역을 선택하면 번역이 원래 위치에 나타납니다.

끊김 없음 🎯 정밀 영역 선택 원래 레이아웃 유지 🤖 20+ AI 引擎
여행 vlog · 메뉴 / 간판 / 자막
해외 여행 vlog 속 식당 메뉴, 간판 → 일시정지 → 영역 선택 → 번역이 나타납니다. 디지털 리뷰 속 텍스트 오버레이, 벤치마크 차트 등 자막으로 번역할 수 없는 것도 선택 영역 번역으로 해결.
메뉴 번역
튜토리얼 PPT / 판 / 코드
Coursera / Udemy 온라인 강의 → 일시정지 → PPT 정의, 칠판 필기, 코드 시연 영역 선 → 원 위치에 번역이 표시됩니다.

벤치마크 번역
만화 원본 · 대화 말풍선
일본 만화/한국 만화 → 보고 싶은 말풍선을 선택 → 번역이 옆에 나타납니다. 원본을 "매끄럽게" 즐길 수 있는 최초의 경험.
📷 만화 번역
SNS 밈 / 뉴스 / 해외 쇼핑
Reddit / 트위터의 밈, 이모티콘 — 이전에는 이해할 수 없었습니다. 해외 쇼핑몰의 상품명, 가격, 옵션도 영역 선택으로 즉시 파악. 뉴스 다큐멘터리의 역사 자료, 데이터 차트도 일시정지 후 천천히 볼 수 있습니다.
